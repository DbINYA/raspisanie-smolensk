# Неофициальное расписание Смоленского филиала Финуниверситета

Интерактивное расписание направления «Юриспруденция» для 4 курса, 7 семестра. Текущая версия: **2.0.0**. Его можно открыть в браузере или установить как приложение.

> [!IMPORTANT]
> Это независимый добровольческий и неофициальный проект. Он не создан, не одобрен и не поддерживается Финансовым университетом при Правительстве Российской Федерации или его Смоленским филиалом.

## Возможности

- расписание направления «Юриспруденция», открытое по умолчанию;
- просмотр текущей, предыдущей и следующей учебной недели;
- автоматическое определение числителя или знаменателя;
- отображение занятий по дням, времени, аудиториям и типу занятия;
- установка как PWA и доступ к уже загруженному расписанию без интернета;
- работа без сервера, внешних библиотек и установки зависимостей.

## Использование

1. Скачайте содержимое репозитория в одну папку.
2. Запустите локальный сервер:

   ```text
   python -m http.server 8000
   ```

3. Откройте `http://localhost:8000` в современном браузере.

Обычное открытие `index.html` напрямую также поддерживается, но установка PWA и офлайн-кэш работают только при публикации по HTTPS или через `localhost`.

Для публикации через GitHub Pages разместите содержимое репозитория в корне сайта и включите Pages для основной ветки в настройках репозитория.
