# Неофициальное расписание Смоленского филиала Финуниверситета

Интерактивное расписание 4 курса, 7 семестра. Текущая версия: **1.0.0**. Откройте `index.html` в браузере.

> [!IMPORTANT]
> Это независимый добровольческий и неофициальный проект. Он не создан, не одобрен и не поддерживается Финансовым университетом при Правительстве Российской Федерации или его Смоленским филиалом.

## Возможности

- выбор направления подготовки;
- просмотр текущей, предыдущей и следующей учебной недели;
- автоматическое определение числителя или знаменателя;
- отображение занятий по дням, времени, аудиториям и типу занятия;
- работа без сервера, внешних библиотек и установки зависимостей.

## Использование

1. Скачайте `index.html` и `DISCLAIMER.txt` в одну папку.
2. Откройте `index.html` в современном браузере.

Для публикации через GitHub Pages разместите оба файла в корне репозитория и включите Pages для основной ветки в настройках репозитория.

## Версии

Проект использует [семантическое версионирование](https://semver.org/lang/ru/):

- `MAJOR` — несовместимые изменения поведения или структуры;
- `MINOR` — новые обратно совместимые возможности;
- `PATCH` — исправления без изменения существующих возможностей.

Текущий номер хранится в файле `VERSION`, отображается в футере сайта, а изменения перечисляются в `CHANGELOG.md`. При выпуске новой версии эти три места обновляются вместе.
