# История изменений

Все заметные изменения проекта фиксируются в этом файле. Номера выпусков следуют семантическому версионированию.

## [Не выпущено]

### Добавлено

- прогресс выполнения каждой пары с отметкой о завершении.

### Изменено

- обводка текущего дня стала заметнее.

## [2.0.0] — 2026-10-13

### Добавлено

- установка сайта как PWA и офлайн-доступ к ранее загруженному расписанию;
- компактное предложение установки с отдельной инструкцией для iPhone.

### Изменено

- в футер добавлена ссылка на официальное расписание Финансового университета.
- расписание теперь содержит только направление «Юриспруденция», которое открывается по умолчанию.

### Удалено

- сведения о преподавателях удалены из расписания и исходного HTML.
- фильтр выбора направления и данные остальных направлений.

## [1.0.0] — 2026-10-12

### Добавлено

- интерактивное расписание 4 курса, 7 семестра;
- определение числителя и знаменателя по выбранной неделе;
- навигация между учебными неделями;
- переключение направлений подготовки;
- отображение дат, типов занятий, преподавателей и аудиторий;
- адаптивное отображение для настольных и мобильных экранов;
- уведомление о неофициальном статусе проекта и файл `DISCLAIMER.txt`;
- номер версии в футере сайта и файл `VERSION`.
